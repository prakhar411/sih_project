Project Name: Aapdarthi
Project Type: Disaster Management Mobile Application
Technology Stack:

Frontend: Flutter (Dart)
State Management: Riverpod
Backend: PostgreSQL
Cloud Integration: Firebase
APIs: Location, Weather, SMS, Notifications
Version Control: GitHub
IDE: Visual Studio Code
1. Introduction
Aapdarthi is a disaster management mobile application designed to assist users during emergency situations such as Glacial Lake Outburst Floods (GLOF), natural calamities, and other disasters. It provides features to enhance user safety, real-time disaster updates, weather information, offline assistance, and integration with NGOs and government bodies.

2. Objective
The primary objective of Aapdarthi is to deliver timely and accurate information about disasters, offer rescue and assistance options to affected individuals, and facilitate collaboration between users, NGOs, and government agencies. It aims to bridge the gap between immediate first responders and affected communities.

3. Features
Offline Location Tracking: Users can access their location even without an internet connection by tapping the 'Instant Help' button.
Real-time Disaster Updates: Users receive live updates on disaster occurrences and guidance to ensure safety.
Weather and AQI Information: The app provides weather data and the Air Quality Index for the user's location.
Chatbot Assistance: A chatbot is integrated for quick information and help during distress.
Task Management: Users can manage their safety tasks, and overdue tasks are highlighted in red. Completed tasks have a green background.
Incident Reporting: Users can report incidents such as GLOFs and receive instructions on how to act in emergency situations.
In-app Donation: Supports donations to NGOs working in disaster-hit areas using the integrated payment feature.
Alerts and Notifications: The app sends alerts for nearby disasters and public safety measures.
User Profile Management: Users can manage personal data, track their activities, and engage with other community members.
Government Collaboration: Works with government agencies for real-time GLOF monitoring and women's safety features.
NGO Partnership: The app allows collaboration with NGOs for first-response activities.
4. Backend Architecture
The application uses a PostgreSQL database for storing and managing user data, tasks, and disaster reports. Firebase handles authentication and real-time notifications. APIs provide geolocation services and weather updates, ensuring the app remains functional even in low-internet environments.

5. Future Enhancements
Advanced Location Tracking: Incorporating mesh networking and emergency SMS services to allow communication in areas with no cellular coverage.
Personalization: Enhanced personalization features to provide targeted disaster information based on the user's geographic location.
Rescue Teams: Direct coordination with government rescue teams to assist users.
Community Support: Integration with NGOs and local communities for disaster response.
6. Conclusion
Aapdarthi is designed to provide essential aid to people during natural disasters by offering real-time updates, offline assistance, and collaboration with rescue teams. The app aims to improve the resilience of communities in disaster-prone areas.
